Aurangabad, Bihar**. It contains a PRD, TRD, Design Document, UI/UX
Document, Security Document, and Bug Fixes & QA Document.

## Important image note

The current environment could read the photo gallery descriptions but
could not reliably download the underlying original image files.
Therefore, this ZIP does **not** pretend to contain extracted original
resort photographs. `assets/reference-photo-links/PHOTO-SOURCING.md`
records the source pages and an implementation workflow for obtaining
owner-approved images. Do not hotlink Justdial/Facebook images in
production without permission and stable direct image URLs. Prefer
images supplied by the resort owner or downloaded with permission.

## Recommended first phase

Build a static, responsive marketing website with enquiry/contact
actions. Do not implement online payment, live room availability,
booking inventory, or a database until the owner confirms requirements.

## Before publishing, confirm

1.  Preferred phone and WhatsApp number.
2.  Exact list of services/facilities.
3.  Room types, room count, prices, and availability, if accommodation
    is offered.
4.  Event/banquet capacity and booking process.
5.  Restaurant/food details and operating hours.
6.  Official logo, brand colors, and owner-approved photos.
7.  Whether online booking is desired or enquiry-only is sufficient.
8.  Permission to use Facebook/Justdial images and reviews.
